## Summary

Translated DBEMT_AB4 (77-line Adams-Bashforth 4-step integrator). No infrastructure changes needed — all patterns proven by RK4. First C++-calls-C++ callee (AB4 calls RK4 for bootstrap) and first xdot[4] history access in a translation.

Results: 20/20 KGen IDENTICAL, 17/17 baselines PASS.

## Key Patterns Exercised

**xdot history shift:** `OtherState->xdot[3].element[x_idx] = OtherState->xdot[2].element[x_idx]` etc. — struct copy through the `dbemt_continuousstatetype_view_t[4]` embedded array. Validates the KD9 fixed-size view array infrastructure end-to-end.

**OtherState%n(i,j):** 2D integer ALLOCATABLE accessed as `OtherState->n[(j-1)*OtherState->n_n_rows + (i-1)]` — time step tracking for history validation.

**C++-calls-C++:** AB4 calls `dbemt_rk4_c(...)` for n≤2 bootstrap. In the kernel, this goes through a bridge to the original Fortran. In production, the wrapper calls the C++ RK4 directly.

**CalcContStateDeriv output into xdot:** The derivative result is written directly into `&OtherState->xdot[0].element[x_idx]` — no intermediate copy needed since the output parameter is a pointer to the element struct.

## Translation Notes

- Shared `SetErrStat()` from `vit_nwtc.h` — no lambda
