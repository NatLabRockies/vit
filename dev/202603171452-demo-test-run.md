# Demo Pipeline Test Run

**Date:** 2026-03-17
**Status:** completed
**Scope:** end-to-end pipeline validation

## Background

The VIT demo script (`demo/demo_script.md`) is a two-phase interactive walkthrough that demonstrates the full VIT pipeline on ROSCO's `interp1d` function. It was originally run some time ago, and the ROSCO working directory still had artifacts from that run (patched Functions.f90, CMakeLists.txt, generated C++ files, kernel directories). This test run validates that the entire pipeline still works after the ~3 week gap since the last development activity.

## Pre-Demo Cleanup

The demo script includes a "Pre-Demo Setup" section that doubles as post-demo cleanup. The container (vit-dev, running on Colima) had to be started from scratch:

1. **Colima start** — The Docker VM was not running. Started with `colima start`, then `docker start vit-dev`.
2. **ROSCO reset** — `git checkout .` reverted 4 tracked files (Functions.f90, CMakeLists.txt, and two others modified by prior integration). Removed generated C++ files (`*_cpp.cpp`), `interp1d.cpp`, and `kernel/interp1d/`.
3. **Baseline build** — Clean Fortran build from scratch (cmake + make), copied libdiscon.so, ran simulation to capture `baseline_output.txt` (242 lines).

## Demo Execution (Acts 1–6)

### Act 1: Read and Understand
Read `interp1d` from Functions.f90 lines 94–152. Function is a 1-D linear interpolation with:
- Two assumed-shape arrays (`xData(:)`, `yData(:)`)
- Derived type argument (`TYPE(ErrorVariables)`)
- REAL(DbKi) return type
- Boundary clamping + linear search algorithm

### Act 2: Translate
Copied canonical translation from `translations/interp1d.cpp` to `ROSCO/interp1d.cpp`. The C++ version uses per-array size parameters (`n_xData`, `n_yData`) and 0-based indexing.

### Act 3: Extract Runtime State
Command: `vit extract interp1d -f rosco/controller/src/Controllers.f90 -l 62`

Result: **Extraction successful, 20 cases captured.** Output confirmed:
